**What it means.** These are hospital case reports, where almost every case lists a creatinine value. The reader was built to find a test reported in a primary-care note ("trae analítica de la mutua: FGe 63"), and returns one finding per note. Missing a creatinine value in a hospital report is a miss by the definition, but it does not change an order here: a note never removes an eGFR order (round 13, R5). No CAC finding existed in this sample, so recall for the findings that can remove an order is not measured.

Deviation: one labelling agent (part 2, 100 cases) searched its file for kidney terms instead of reading every sentence.
